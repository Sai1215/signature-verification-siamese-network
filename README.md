# Signature Verification Using Siamese Neural Networks

## Project Overview

This project implements a handwritten signature verification system using a Siamese Neural Network and convolutional neural networks.

The model compares two signature images and predicts whether they belong to the same-writer class or the different/forged class.

## Technologies Used

- Python
- Google Colab
- TensorFlow and Keras
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Pillow
- CEDAR Handwritten Signature Dataset

## Workflow

1. Download and preprocess signature images.
2. Generate genuine and forged signature pairs.
3. Train a Siamese Neural Network.
4. Evaluate the model using accuracy, precision, recall, F1-score and a confusion matrix.
5. Compare two uploaded signature images.

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Allow the dataset to download.
4. Train and evaluate the model.
5. Upload two signature images for comparison.

## Limitations

This is an educational project. Its predictions are not proof of authenticity and should not be used for legal, financial or identity-verification decisions without independent validation.
